# 🍴 Royal Menu - Interactive Restaurant Web App

An interactive, responsive, and modern web-based restaurant menu designed for seamless user experience. Features category browsing, real-time search, and a dynamic cart calculator.

---

## ✨ Features
- **Responsive Layout:** Grid-based layout optimized for mobile, tablet, and desktop screens.
- **Real-Time Search:** Instant filtering of menu items as the user types.
- **Dynamic Cart Calculator:** Live price calculation and item count updates.
- **Modern UI:** Dark-mode theme with gold and orange accents.

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
